Este es el primer artículo que escribimos sobre el lenguaje [Python](http://www.manualweb.net/python/) y no podía dejar de ser otro que no fuese un Hola Mundo en [Python](http://www.manualweb.net/python/).


Pero antes de ponernos manos a la obra revisemos un poco las características del lenguaje [Python](http://www.manualweb.net/python/) y veamos como podemos preparar nuestro entorno de trabajo para acometer el Hola Mundo en [Python](http://www.manualweb.net/python/).


## Hablando un poco de Python


[Python](http://www.manualweb.net/python/) es un lenguaje de programación interpretado cuyo principal objetivo es tener un código legible, que cuando escribas un programa en [Python](http://www.manualweb.net/python/) parezca que estás escribiendo pseudo-código.


Dentro de las características de [Python](http://www.manualweb.net/python/) encontramos:

- **Sencillez de programación**, ya hemos comentado que es la característica más básica, hacer programas sencillos de entender.
- **Multiplataforma**, tenemos versiones de [Python](http://www.manualweb.net/python/) para diferentes plataformas: Linux, Mac, Windows,...
- **Interpretado**, no tenemos que compilar el código fuente antes de ejecutarlo.
- **Tipado dinámico**, las variables no son declaradas con un tipo, si no que cogen el tipo atendiendo al valor que se les asigna.
- **Orientación a objetos**, se utilizar este paradigma de desarrollo que nos permite encapsular funcionalidades y datos en una clase.
- **Extensión con librerías**, existen múltiples librerías que permiten extender la funcionalidad básica del lenguaje y lo hace mucho más rico.

## Descargar Python


Nos podemos descargar [Python](http://www.manualweb.net/python/) desde [https://www.python.org/downloads/](https://www.python.org/downloads/). Simplemente tendremos que seleccionar la plataforma sobre la que lo queremos instalar: Mac, Windows, Linux/Unix,...


Contamos con dos líneas de [Python](http://www.manualweb.net/python/), la versión 2.x o la versión 3.x. Dependiendo de la que quieras instalar deberás de descargarte un fichero u otro.


Una vez descargado solo tendremos que instalar el ejecutable, y ya tendremos [Python](http://www.manualweb.net/python/) instalado.


## Modo interactivo


[Python](http://www.manualweb.net/python/) incluye un modo interactivo de tal manera que puedas ir escribiendo el programa en forma de comandos. De esta manera, según vayamos insertando sentencias el propio interprete las va ejecutando y mostrándonos su resultado.


Para cargar el modo interactivo de [Python](http://www.manualweb.net/python/) simplemente tienes que escribir:


```bash
python
```


O para una versión específica:


```bash
python3.5
```


## Hola Mundo en Python


Lo que vamos a hacer es crear un fichero que llamaremos [`holamundo.py`](http://holamundo.py/) el cual abriremos con un editor de textos, el que queramos: Sublime, Atom, Nano,...


> La extensión de los fichero de [Python](http://www.manualweb.net/python/) será .py


Lo que vamos a realizar es escribir por consola "Hola Mundo", así que utilizaremos la sentencia `print` seguida de la cadena de texto. La cadena de texto la pondremos entre dobles comillas.


```python
print("Hola Mundo")
```


Para ejecutar nuestro programa Hola Mundo en [Python](http://www.manualweb.net/python/) deberemos de escribir en consola:


```bash
python [holamundo.py](http://holamundo.py/)
```


Y veremos como aparece la frase en consola.


Como podéis ver es muy sencillo el escribir un programa de Hola Mundo en [Python](http://www.manualweb.net/python/). Espero que os haya resultado interesante.
