# Estilos de texto y tipografía en CSS


La tipografía es uno de los pilares del diseño web. CSS ofrece un amplio conjunto de propiedades para controlar cómo se muestra el texto: fuentes, tamaños, espaciados, alineación y decoración.


En esta sección se abordan propiedades como `font-family`, `font-size`, `font-weight`, `line-height`, `text-align` y `text-decoration`, así como el uso de fuentes web, buenas prácticas tipográficas y consideraciones de legibilidad.


Estos contenidos están orientados a lograr textos claros, accesibles y visualmente coherentes en cualquier tipo de interfaz.
