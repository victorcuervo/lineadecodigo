# Layout en CSS: estructurando la página


El layout define cómo se organizan los bloques principales de una interfaz. Antes de Grid y Flexbox, CSS ya ofrecía mecanismos fundamentales para estructurar una página.


Aquí se cubren propiedades generales como `display`, `float`, `clear`, `overflow`, dimensiones y control del flujo del documento.


Esta sección sirve como base conceptual para entender los sistemas de layout modernos.
