# Posicionamiento en CSS: control absoluto de los elementos


CSS permite posicionar elementos de múltiples formas, desde flujos naturales hasta posicionamiento explícito.


En esta sección se explican los distintos valores de `position` (`relative`, `absolute`, `fixed`, `sticky`), el uso de coordenadas (`top`, `left`, etc.) y patrones habituales como overlays, tooltips y encabezados fijos.


Un conocimiento sólido de posicionamiento es esencial para interfaces complejas.
