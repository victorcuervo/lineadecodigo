# CSS Grid: diseño bidimensional avanzado


CSS Grid permite crear layouts complejos de forma declarativa y predecible, trabajando simultáneamente en filas y columnas.


Aquí encontrarás guías sobre grid containers, tracks, áreas, alineación y patrones de diseño completos.


Grid es la herramienta más potente para layouts estructurales en CSS moderno.
