# Flexbox en CSS: diseño unidimensional moderno


Flexbox es un sistema de layout diseñado para distribuir espacio y alinear elementos en una sola dimensión.


En esta categoría se explican contenedores flex, ejes, alineación, orden, crecimiento y reducción de elementos, con ejemplos prácticos aplicados a componentes reales.


Flexbox es ideal para interfaces dinámicas y adaptables.
