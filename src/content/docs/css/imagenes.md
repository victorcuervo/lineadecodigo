# Imágenes en CSS: adaptación, recorte y presentación


Las imágenes juegan un papel clave en la experiencia de usuario, y CSS proporciona herramientas para integrarlas correctamente en cualquier diseño.


Esta sección cubre el uso de imágenes en HTML y como fondos CSS, propiedades como `object-fit` y `object-position`, control de proporciones y técnicas para adaptar imágenes a distintos contextos y tamaños de pantalla.


El objetivo es optimizar tanto la estética como la usabilidad.
