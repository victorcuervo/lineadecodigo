# Accesibilidad en CSS: diseñar para todos


CSS juega un papel crucial en la accesibilidad web. Un mal uso del color, el foco o las animaciones puede dificultar el acceso a muchos usuarios.


Aquí se tratan temas como visibilidad del foco, contrastes, preferencias del usuario (`prefers-reduced-motion`, `prefers-color-scheme`) y buenas prácticas inclusivas.


Diseñar con accesibilidad en mente es una responsabilidad profesional.
