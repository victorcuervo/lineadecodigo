# Transformaciones, transiciones y animaciones en CSS


CSS permite añadir movimiento e interactividad sin necesidad de JavaScript.


Aquí se explican `transform`, `transition`, `animation` y `@keyframes`, junto con buenas prácticas de rendimiento y accesibilidad.


El objetivo es mejorar la experiencia de usuario sin sobrecargar la interfaz.
