# Variables y funciones CSS: estilos dinámicos y reutilizables


Las custom properties y funciones CSS permiten crear estilos más flexibles y mantenibles.


En esta categoría se abordan variables CSS, `calc()`, `clamp()`, `min()` y `max()`, así como patrones para escalabilidad y tematización.


Es una sección clave para CSS moderno y profesional.
