# Media Queries y diseño responsive en CSS


Las Media Queries permiten adaptar el diseño a distintos dispositivos y contextos de uso.


En esta sección se tratan breakpoints, estrategias mobile-first, consultas basadas en características del dispositivo y preferencias del usuario.


Es un pilar fundamental del diseño web moderno.
