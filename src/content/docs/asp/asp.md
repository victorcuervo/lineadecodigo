**ASP (Active Server Pages)** es un lenguaje de servidor desarrollado por Microsoft que nos permite desarrollar páginas web. Actualmente **ASP (Active Server Pages)** ha evolucionado a ASP.Net dentro de la plataforma Microsoft.Net


**ASP (Active Server Pages)** no es un lenguaje de programación en si mismo sino que es un conjunto de objetos que nos proporcionan funcionalidades para acceder a las bases de datos (ADO), a los ficheros (FileSystemObjects),…


El lenguaje de programación sobre el que se apoya **ASP (Active Server Pages)** y que permite definir variables, constantes, flujos de control, funciones,… puede ser VBScript o Javascript.
