## Listas ordenadas en HTML


En este ejemplo vamos a ver como podemos crear listas ordenadas en [HTML](https://www.manualweb.net/html/). Las listas ordenadas en [HTML](https://www.manualweb.net/html/) nos sirven para mostrar una lista de elementos con un orden. Para ello en [HTML](https://www.manualweb.net/html/) se visualiza como una lista, anteponiendo a cada uno de los elementos el orden que tiene en la lista.


## Elemento OL


El elemento que nos permite crear listas ordenadas en [HTML](https://www.manualweb.net/html/) es el **elemento OL**.


```html
<ol>
</ol>
```


## Elemento LI


Y cada uno de los elementos de las listas ordenadas en [HTML](https://www.manualweb.net/html/) se establecen mediante el [elemento LI](https://www.w3api.com/HTML/li/).


```html
<li>Elemento de la lista</li>
```


## Ejemplo: Provincias españolas


Si lo que queremos es mostrar una lista ordenada con las provincias españolas atendiendo al número de habitantes tendremos que utilizar el siguiente código [HTML](https://www.manualweb.net/html/):


```html
<ol>
  <li>Madrid</li>
  <li>Barcelona</li>
  <li>Valencia</li>
  <li>Alicante</li>
  <li>Sevilla</li>
</ol>
```


## Resultado


Cada uno de los elementos va dentro del [elemento LI](https://www.w3api.com/HTML/li/) y todos los elementos los hemos anidados en la lista ordenada, es decir, dentro del **elemento OL**. 


El resultado de la lista ordenada en [HTML](https://www.manualweb.net/html/) que tendremos por pantalla será el siguiente:

1. Madrid
2. Barcelona
3. Valencia
4. Alicante
5. Sevilla

Vemos que delante de cada uno de los elementos de la lista ordenada aparece el número de su orden. Espero que os haya servido el ejemplo para poder montar vuestras listas ordenadas en [HTML](https://www.manualweb.net/html/).
