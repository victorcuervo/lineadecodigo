Si el otro día veíamos como poner un [subíndice en HTML](http://lineadecodigo.com/2009/01/15/subindice-en-html/), hoy vamos a ver como poner un superíndice en [HTML](https://www.manualweb.net/html/).


Esto nos ayudará cuando en nuestras páginas web tengamos que poner cosas como:

- Fórmulas matemáticas: E = mc<sup>2</sup>
- Medidas: 20 km<sup>2</sup>
- Referencias a pie de página: ...según lo citado en Linea de Código<sup>1</sup>...

## El elemento SUP


En este caso, para poner un superíndice con [HTML](https://www.manualweb.net/html/) necesitamos del elemento SUP. Este elemento contendrá el superíndice entre una etiqueta de inicio y otra de cierre.


```html
<sup>texto en superíndice</sup>
```


## Ejemplos de uso


El código necesario para expresar los ejemplos anteriores sería el siguiente:


```html
<!-- Fórmula matemática -->
<p>E = mc<sup>2</sup></p>

<!-- Medida de superficie -->
<p>20 km<sup>2</sup></p>

<!-- Referencia a pie de página -->
<p>...según lo citado en Linea de Código<sup>1</sup>...</p>
```


Algo realmente útil y sencillo para añadir superíndices en tus documentos HTML.
