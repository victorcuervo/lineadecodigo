Si está escribiendo fórmulas matemáticas es posible que te surja la duda de cómo poner una raíz cuadrada en tu página [HTML](https://www.manualweb.net/html/). Para poder hacer esto utilizamos las entidades HTML.


## La entidad de raíz cuadrada


En concreto el código de la entidad de la raíz cuadrada es **8730**. Para usar esta entidad numérica en HTML, debemos añadir `&#` delante del código y `;` al final del código.


## Cómo escribir la raíz cuadrada


En nuestra página [HTML](https://www.manualweb.net/html/) escribiríamos lo siguiente:


```html
<p>Calcular la raíz cuadrada de 16.</p>
<p>&#8730;16 = 4</p>
```


## El resultado


Y el resultado sería:


Calcular la raíz cuadrada de 16.


√16 = 4


Sencillo y útil. Con esta entidad HTML podemos representar fórmulas matemáticas con raíces cuadradas en nuestras páginas web de forma correcta y estándar.
