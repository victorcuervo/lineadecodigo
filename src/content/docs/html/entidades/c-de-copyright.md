Es muy normal que estemos haciendo un [pie de página en nuestra web](https://lineadecodigo.com/html5/pie-de-pagina-en-html5/) y que en dicho [pie de página](https://lineadecodigo.com/html5/pie-de-pagina-en-html5/) queramos poner la referencia al copyright de la página. Lo que se conoce como © de copyright. El copyright viene a reflejar los derechos de autor sobre la obra literaria, artística o científica, tanto publicada como aquellas que todavía no se han publicado.


La forma correcta de poner un copyright es la siguiente:


```html
"Copyright [fechas] por [autor/propietario]"
```


Ponerlo esto en [HTML](https://www.manualweb.net/html/) no tiene ningún misterio. Sería la siguiente [línea de código](https://lineadecodigo.com/):


```html
Copyright 2006 por Línea de Código
```


Puro y simple texto. La palabra copyright puede ser sustituida por una c rodeada de un círculo. Ya que si utilizamos el símbolo (c), este, no tendrá un valor legal.


En este caso tendremos que apoyarnos en [las entidades de HTML](https://manualweb.net/html/entidades-html/). Las [entidades](https://manualweb.net/html/entidades-html/) son un conjunto de abreviaturas que nos ayudan a representar los caracteres especiales, como el copyright, de una forma estándar.


Para poder incluir una entidad dentro de nuestra página web deberemos de utilizar la siguiente estructura:


```html
&codigo;
```


Es decir, pondremos un ampersand `&` seguido del código de la entidad y terminamos con un punto y coma `;`.


En este caso, la [entidad](https://manualweb.net/html/entidades-html/) del copyright es `&copy;`. De esta forma, nuestro código [HTML](https://www.manualweb.net/html/) quedaría de la siguiente forma:


```text
&copy; 2006 Línea de Código
```


Otra forma sería utilizando el código asociado al copyright, que es &#169;. En este caso, la [línea de código](https://lineadecodigo.com/) sería la siguiente:


```text
&#169; 2006 Línea de Código
```


Ambos, tanto la entidad con el texto como la entidad con el código, darían el mismo resultado.


> 💻 © 2006 por Línea de Código


Con esto ya sabrás como puedes incluir la © de copyright dentro de tu página web, si bien puedes [leer más sobre el copyright en la Wikipedia](http://es.wikipedia.org/wiki/Copyright) para conocer algo más sobre ella.
