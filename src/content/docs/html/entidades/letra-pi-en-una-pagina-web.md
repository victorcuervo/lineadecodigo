Si estamos montando una web [HTML](http://www.manualweb.net/tutorial-html/) orientada a temas de ciencias: matemáticas, químicas, físicas,… es muy probable que nos encontremos ante la necesidad de utilizar una serie de símbolos estándar, entre los cuales, seguro que está la letra PI (Π).


Si queremos mostrar la letra PI en un documento [HTML](http://www.manualweb.net/tutorial-html/) deberemos de recurrir a su representación mediante el carácter ASCII. El carácter ASCII que le corresponde es el 928. A si que simplemente deberemos de anteponerle &# y ponerle detrás un punto y coma (;).


A si que podríamos tener la siguiente línea de código para representar su valor numérico:


```html
&#928; = 3,1416
```


La página web nos mostrará lo siguiente:


```shell
Π = 3,1416
```
