# Semántica


Esta categoría trata los elementos que aportan **significado estructural** al documento, fundamentales para accesibilidad, SEO y mantenibilidad.


## Secciones principales

- `<header>`
- `<nav>`
- `<main>`
- `<footer>`

## Organización de contenido

- `<section>`
- `<article>`
- `<aside>`

## Contenido relacionado

- `<address>`
- `<figure>`
- `<figcaption>`

## Diálogos

- `<dialog>`
- Uso semántico de modales y cuadros de interacción

Se enfatiza cuándo usar semántica frente a contenedores genéricos.
