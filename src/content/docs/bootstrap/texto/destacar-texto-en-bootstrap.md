## La clase lead en Bootstrap


Cuando estemos manejando contenido en Bootstrap vamos a ver que es muy sencillo destacar texto. La idea de destacar texto en Bootstrap es conseguir que ciertos párrafos tengan más relevancia que otros.


## Crear párrafos básicos


Lo primero será poner dos párrafos de texto:


```html
<p>Texto destacado</p>
<p>Texto que acompaña al texto destacado, pero que se visualiza normal.</p>
```


Vemos que hemos utilizado el elemento HTML `p` para poder crear dos párrafos de texto.


## Aplicar la clase lead


Ahora vamos a destacar texto en Bootstrap, para ello vamos a utilizar la clase `lead`. Esta clase la vamos a asignar al párrafo a destacar mediante el atributo `class`. Ahora el código nos quedará de la siguiente forma:


```html
<p class="lead">Texto destacado</p>
<p>Texto que acompaña al texto destacado, pero que se visualiza normal.</p>
```


El primer párrafo que es el que contiene el texto destacado con Bootstrap será el que tenga una visualización más grande de los dos.
