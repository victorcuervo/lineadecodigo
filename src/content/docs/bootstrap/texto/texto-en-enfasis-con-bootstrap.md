[Bootstrap](http://www.manualweb.net/bootstrap/) nos permite varias formas de poner un texto en énfasis. El texto en énfasis con [Bootstrap](http://www.manualweb.net/bootstrap/) se maneja mediante una serie de clases de utilidad las cuales dan un formato a dicho texto.


El formato del texto en énfasis con [Bootstrap](http://www.manualweb.net/bootstrap/) hace que dicho texto sobresalga del texto del texto contenido en la página.


## Tipos de texto en énfasis


Los formatos de texto que nos proporciona [Bootstrap](http://www.manualweb.net/bootstrap/) son:

- **Texto apagado**, muestra el texto en un color gris que hace parecer que el texto está deshabilitado. La clase que lo representa en `text-muted`.
- **Texto primario**, nos muestra un énfasis normal. La clase que lo representa es `text-primary`.
- **Texto de una acción OK**, mediante un color verde nos muestra texto enfatizado que representa una actividad de OK. La clase que lo representa es `text-success`.
- **Texto informativo**, nos sirve para mostrar texto de información al usuario. La clase que lo representa es `text-info`.
- **Texto para una alarma**, sirve para mostrar énfasis en un texto de alarma o warning del usuario. La clase que lo representa es `text-warning`.
- **Texto para un error**, énfasis para textos de error. La clase que lo representa es `text-danger`.

## Código de ejemplo


Siguiendo lo explicado de las formas de poner texto en énfasis con [Bootstrap](http://www.manualweb.net/bootstrap/) podemos codificar lo siguiente:


```html
<p class="text-muted">Texto apagado</p>
<p class="text-primary">Texto primario</p>
<p class="text-success">Texto para una acción de OK</p>
<p class="text-info">Texto informativo</p>
<p class="text-warning">Texto para una alarma</p>
<p class="text-danger">Texto para un error</p>
```


Vemos que cada elemento tiene su clase [Bootstrap](http://www.manualweb.net/bootstrap/) dependiendo del tipo de énfasis que queramos utilizar.
