Un documento XML está compuesto por elementos delimitados por etiquetas de apertura y cierre. Estos elementos pueden contener texto, atributos u otros elementos, formando una estructura jerárquica en forma de árbol.


Para que un XML sea considerado bien formado debe cumplir reglas estrictas: todas las etiquetas deben cerrarse correctamente, respetar el anidamiento, utilizar un único elemento raíz y mantener la sensibilidad a mayúsculas y minúsculas.

- **Elementos y etiquetas**

	Etiquetas de apertura, cierre y elementos vacíos.

- **Atributos**

	Uso correcto, cuándo emplearlos y buenas prácticas.

- **Jerarquía y anidamiento**

	Relación padre–hijo y estructura en árbol.

- **Documento bien formado**

	Reglas que debe cumplir un XML para ser procesable.
