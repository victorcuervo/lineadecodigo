XML (eXtensible Markup Language) es un lenguaje de marcado orientado al almacenamiento y transporte de datos estructurados. A diferencia de HTML, XML no define cómo se muestran los datos, sino cómo se organizan y describen.


Entre sus principales características destacan la extensibilidad, la legibilidad tanto para humanos como para máquinas y su independencia de plataforma y lenguaje. XML se utiliza ampliamente en integración de sistemas, configuración de aplicaciones, intercambio de información y definición de estándares industriales.

- **¿Qué es XML?**

	Definición, propósito, diferencias frente a HTML y otros formatos de intercambio de datos.

- **Características clave**

	Lenguaje extensible, autodescriptivo, independiente de plataforma y de proveedor.

- **Casos de uso comunes**

	Intercambio de datos, configuración de aplicaciones, almacenamiento estructurado.
