# Texto


Agrupa los elementos destinados a **contenido textual y tipográfico**.


## Encabezados

- `<h1>` a `<h6>`
- Jerarquía correcta

## Texto básico

- `<p>`
- `<strong>`
- `<em>`
- `<small>`
- `<mark>`

## Citas y referencias

- `<blockquote>`
- `<q>`
- `<cite>`

## Código y formato técnico

- `<code>`
- `<pre>`

## Elementos auxiliares

- `<abbr>`
- `<br>`
- `<hr>`
