# Contenedores


Incluye elementos **no semánticos** usados para agrupar contenido o servir como soporte estructural.


## Contenedores genéricos

- `<div>`
- `<span>`

## Plantillas

- `<template>`
- Contenido inerte
- Uso como base para generación dinámica

Se explica por qué deben usarse con criterio y no sustituir semántica.
