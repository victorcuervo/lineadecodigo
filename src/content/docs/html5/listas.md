# Listas


Esta categoría cubre las distintas formas de representar colecciones de elementos.


## Listas no ordenadas

- `<ul>`
- `<li>`

## Listas ordenadas

- `<ol>`
- `<li>`

## Listas de definición

- `<dl>`
- `<dt>`
- `<dd>`

## Casos avanzados

- Listas anidadas
- Buenas prácticas semánticas
