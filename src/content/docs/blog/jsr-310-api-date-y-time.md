## JSR 310: Nueva Especificación


La petición de especificación JSR 310 sobre el API de Fechas y Horas ha pasado la primera criba. La especificación es co-liderada por [Stephen Colebourne](http://www.theserverside.com/user/userthreads.tss?user_id=170798) y Michael Nascimento Santos.


## Propósito del Nuevo API


El propósito de esta nueva especificación es buscar un nuevo API [Java](https://www.manualweb.net/java/) para fechas y hora. Aprendiendo las dos ideas que se han tenido en los API's actuales: la clase Date en su primera versión y su mezcla con Calendar en un segundo intento.


Con la idea de tener un API mucho más comprensivo y fácil de manejar.


## Implementación y Estándar


La implementación estará basada en el estándar **ISO8601**. La idea es intentar que el trabajo sea acogido dentro del futuro Java SE 7.
