JSEclipse es un plugin para Eclipse que permite el manejar código [JavaScript](https://www.manualweb.net/javascript/) (tanto el código [JavaScript](https://www.manualweb.net/javascript/) básico, como el de algunas librerías construidas sobre [JavaScript](https://www.manualweb.net/javascript/), véase [DOJO](http://lineadecodigo.com/categoria/dojo/), [Prototype](http://lineadecodigo.com/categoria/prototype/),...) dentro de proyectos Eclipse de una forma muy sencilla.


## **Características**

- Auto-completado de código [JavaScript](https://www.manualweb.net/javascript/)
- Control y gestión de errores
- Resaltado del código fuente
- Información contextual (menú emergente)
- Soporte de librerías [JavaScript](https://www.manualweb.net/javascript/) ([DOJO](http://lineadecodigo.com/categoria/dojo/), [Prototype](http://lineadecodigo.com/categoria/prototype/), YUI, Qooxdoo).
- Soporte para JavaDoc
- Añade en los wizards la gestión de ficheros .js

## **Versión actual**


JSEclipse 1.5


## **Requisitos**

- Eclipse 3.1 o superior
- JRE 1.5 o superior

## Visión desde Línea de Código sobre JSEclipse


Si quieres trabajar con [JavaScript](https://www.manualweb.net/javascript/) y Eclipse, JSEclipse es el plugin que necesitas. La potencia de autocompletado y la ayuda contextual facilitan en gran medida el desarrollo de código [JavaScript](https://www.manualweb.net/javascript/).


Seguro que más de una vez os habéis quedado pensando en cual era o como era esta o la otra función [JavaScript](https://www.manualweb.net/javascript/).


El auto-completado de JSEclipse resuelve todos nuestros problemas. El único inconveniente es que cuando utilizas código [JavaScript](https://www.manualweb.net/javascript/) fuera de los ficheros .js, todas las funcionalidades del plugin quedan deshabilitadas. Una pena. Si bien, incluso con esto es muy recomendable su uso.
